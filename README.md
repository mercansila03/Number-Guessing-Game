# Number Guessing Game

A simple Python command-line game. The computer picks a random number between 1 and 1000, and you try to guess it. The game tells you whether each guess is too high or too low.

## Requirements

- Python 3.x

## Usage

```bash
python guess_game.py
```

## Example

```
Guess my number between 1 and 1000
Enter your guess: 500
Too high! Try again.
Enter your guess: 250
Too low! Try again.
Enter your guess: 375
Congratulations
```
